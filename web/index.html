Vendor Plan $/mo Quota Basis

Every one of these is opaque: the vendor publishes a price and a multiplier or a message cap and never the token count in between. That gap is the reason the probe exists.

Measure what you actually get 
node probe/probe.js --days 30 --plan claude-max-20x

Reads the token counts Claude Code and Codex already write to ~/.claude/projects and ~/.codex/sessions, prices each model at its vendor's own list rate from the table above, and divides by what you pay. Nothing leaves your machine unless you pass --submit.

Data is one JSON file per vendor in data/providers/, each plan carrying a source URL and a checked date. Logos are inline SVG: geometric marks are reproduced, the rest are monogram badges rather than freehand traces of a trademark. Corrections by pull request.
