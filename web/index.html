Measure what your plan actually gives you 
node probe/probe.js --days 30 --plan claude-max-20x

Reads the token counts Claude Code and Codex already write to ~/.claude/projects and ~/.codex/sessions, prices each model at its vendor's own rate from the table above, and divides by what you pay. Nothing leaves your machine unless you pass --submit.

Data is one JSON file per vendor in data/providers/, each plan carrying a source URL and a checked date. Logos are inline SVG with no external requests. Corrections by pull request.
